This is the "final stage, fully" — and it's free. Cloud Run keeps every deploy as a numbered revision (192 for this one service, back to 2026-05-06) with its digest, timestamp, and deployer — the platform retains it at no cost. Revision N was live from its timestamp until N+1, so this table also answers "what was running on date X" — the original deployments-page question. The churn is real: ~40% of these deploys changed nothing (same digest), and AWS App Runner uts-deployment-api-prod is PAUSED today after two failed deploys — a failure the build feed can't see, because the build was green and the deploy is what broke.

The two clouds share no common tag key. GCP tags by short-SHA (6aad829); AWS ECR tags by version + latest and carries no git SHA at all — so "what commit is this ECR image?" is unanswerable from ECR alone and must be joined via the CodeBuild record. Version tags stopped appearing on GCP images around late June, which lines up with the router reading a version field no sender ever sends.
